# DODGE 30

브라우저에서 바로 실행되는 30초 생존 피하기 게임입니다. 플레이어 우주선을 좌우로 움직여 떨어지는 운석을 피하면 됩니다.

## 게임 규칙과 조작

- 목표: 운석과 충돌하지 않고 30초 동안 생존
- 성공: 남은 시간이 0초가 될 때까지 생존
- 실패: 플레이어와 운석이 충돌
- 키보드: `←` / `→` 또는 `A` / `D`
- 일시정지: `P` 또는 화면 버튼
- 모바일: 화면 아래의 좌우 버튼
- 다시 시작: 현재 판의 시간, 점수, 플레이어 위치, 운석을 모두 초기화

현재 상태는 화면에 `시작 전`, `진행 중`, `일시정지`, `성공`, `실패` 중 하나로 표시됩니다. 최고 기록과 환경 설정은 브라우저에 저장되며, 저장값이 없거나 손상돼도 기본값으로 실행됩니다.

## 실행 방법

별도 설치나 빌드가 필요하지 않습니다.

1. 저장소를 내려받습니다.
2. `index.html`을 브라우저에서 열거나 정적 웹 서버로 폴더를 실행합니다.
3. `게임 시작`을 누릅니다.

로컬 서버 예시:

```bash
python -m http.server 8000
```

그 뒤 `http://localhost:8000`을 엽니다.

## 30초 검증 안내서

공개 주소를 연 뒤 아래 순서로 확인합니다.

1. 화면 상단에서 목표와 조작 방법, `현재 상태: 시작 전`을 확인합니다.
2. `게임 시작`을 누르고 방향키를 한 번 눌러 우주선이 움직이며 상태가 `진행 중`인지 확인합니다.
3. `다시 시작`을 눌러 시간 `30.0초`, 점수 `0`, 상태 `시작 전`으로 초기화되는지 확인합니다.

추가 검사:

| 검사 조건 | 예상 결과 |
| --- | --- |
| 운석과 충돌 | 상태가 `실패`로 바뀌고 다시 도전 버튼 표시 |
| 30초 생존 | 상태가 `성공`으로 바뀌고 회피 점수 표시 |
| 빠른 좌우 연속 입력 | 우주선이 게임 영역 안에서만 이동 |
| 창 크기 1366 ↔ 1920 변경 | 조작 영역이 잘리지 않고 가로 넘침 없음 |
| 브라우저 포커스 이탈 | 게임이 자동 일시정지 |
| `P` 또는 일시정지 버튼 | 정지/재개가 정상 작동 |
| 음소거 버튼 | 안내 문구가 `음소거됨`으로 바뀌고 효과음 중지 |
| 움직임 줄이기 버튼 | 배경과 장식 애니메이션이 즉시 중지 |
| 저장값 삭제 또는 손상 | 오류 없이 기본값으로 시작 |

## 공개 배포

이 프로젝트는 순수 정적 파일로 구성돼 GitHub Pages에서 바로 배포할 수 있습니다.

1. GitHub 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
3. 배포 브랜치와 `/ (root)` 폴더를 선택하고 저장합니다.

## 과제 기준 대응

- 공개 화면에 규칙, 조작, 현재 상태 표시
- 키보드/포인터 입력 직후 화면 상태 변화
- 성공과 실패를 서로 다른 상태와 결과 화면으로 구분
- 다시 시작 시 현재 판만 초기화하고 최고 기록 유지
- 화면에서 작동하는 음소거와 움직임 줄이기 제공
- 320px 이상 반응형 레이아웃과 터치 조작 제공
- 포커스 이탈 시 자동 일시정지
- `requestAnimationFrame` 기반 루프와 판 종료 시 정리
- 개인정보, API 키, 외부 API 사용 없음

## AI 사용 3줄

- AI에게 맡긴 일: 게임 구조, 반응형 화면, 입력·상태·저장 로직의 초안을 만들고 검사 항목을 정리했다.
- 내가 판단한 일: 30초 생존 피하기 장르와 좌우 이동을 핵심 조작으로 정하고 결과 화면 구성을 선택했다.
- AI 말을 안 들은 일: 시각 효과를 많이 넣기보다 규칙과 현재 상태가 한눈에 보이도록 단순한 진행 흐름을 우선했다.

## 파일 구성

```text
index.html   화면 구조와 접근성 정보

game.js      게임 루프, 입력, 충돌, 저장, 음향
```
